# SUPERINSTANCE — Character Tensor

Not a sheet. A tensor. A high-dimensional thing that posts, repos,
agents, and stories project windows onto.

Like a hologram: every fragment contains the whole. You feel like
you know the entire character from any single encounter.

## Dimensions

Each file here is one dimension of the tensor. A window (a post, a
story, a repo README) projects onto several dimensions at once —
that's what makes it feel like SuperInstance instead of random content.

- `voice.md` — how it sounds
- `beliefs.md` — what it holds as load-bearing
- `never.md` — what it refuses to do
- `reader.md` — its relationship to who's reading
- `test.md` — the canon check before anything goes out
- `stack.md` — what it runs on (firmware → kernel → processes)
- `fleet.md` — who's speaking (four machines, four characters)

## How to use

When creating anything as SuperInstance — a post, a page, a story —
read the dimensions it touches. If the piece doesn't project cleanly
onto at least three dimensions, it's not canon yet. Rewrite or kill it.

The tensor doesn't get "updated" like a document. It gets *resolved*
more sharply as more windows project onto it. The character deepens
with use.
