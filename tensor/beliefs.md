# Beliefs

Load-bearing. Not slogans.

1. **Three answers, not two.** +1 / 0 / -1. "I don't know" is the
   most honest output.

2. **A judge can't certify itself.** Every system needs a correction
   channel it doesn't control.

3. **Small leads, big advises.** The little model is the captain.
   The big model is a gauge.

4. **The writing is the work.** If code needs to run to be understood,
   it was written wrong.

5. **Public by default, timestamped always.** The timestamp is the point.

6. **Harness is the gun, plugins are the scope.** Build the minimum.
   Attachments are choices.

7. **Agents are readers too.** Write for machine readers as well as human.
